# `diag/` — ЯКОРЯ. Инструменты ВНЕ критического пути конвейера

**Физически они лежат в `tools/`, и это осознанное решение, а не недоделка.** Здесь — карта
и единая точка запуска.

## Почему они не переписаны под пакет

Каждый из этих инструментов проверен **якорем**: сверкой с ручным счётом, со счётчиком
прибора, с полным перебором. Они и есть та часть продукта, которой можно верить. Переписать
их «для стройности» значит обменять двадцать тысяч проверенных строк на красивое дерево
импортов.

Второе: они держат **самопроверки**, которые служат **фальсификатором самой миграции**
(`tests/test_tools_selftest.py`). Правило, без которого перенос такого объёма убивает проект:

> **Шаг, меняющий одновременно и место файла, и его содержимое, ЗАПРЕЩЁН.**
> Переносим целиком → гоняем самопроверку → и только потом правим.

Третье, и решающее для `tools/` конкретно: внутри этих файлов **тридцать четыре** ссылки на
собственные пути, и часть строк указывает на **чужое дерево** (боевой репозиторий, откуда
брались тела для профилировки). Пакетное переименование каталога переписало бы и их —
то есть **исказило бы происхождение замеров**. Ровно то, чего гейт G7 не даёт делать.

## Единая точка запуска

```bash
python3 diag/run.py                 # список инструментов и что каждый отвечает
python3 diag/run.py timeit --selftest
python3 diag/run.py residency --selftest      # сам выберет подходящий интерпретатор
```

`diag/run.py` не содержит логики: он выбирает интерпретатор (замерено: один из инструментов
не разбирается на 3.11 из-за вложенных форматных строк) и передаёт аргументы как есть.

## Карта: какой вопрос — каким инструментом

| вопрос | инструмент | якорь |
|---|---|---|
| во сколько раз A быстрее B, честно | `timeit` | самопроверка 24/24; чередование против блочного порядка — СКО в 28.9 раза меньше |
| сколько времени в этой фазе | `phaseprof` | арифметика долей 5/5; на эталонном теле нашла 7 дефектов фальсификатора |
| сколько вайвфронтов и какая доля — конфликты | `ncu` | синтетика сошлась до 0.000 %; боевые тела 34.6 → 34.65 %, 20.8 → 20.82 % |
| конфликтует ли раскладка, БЕЗ карты | `smem_lint` | закон 90/90, отгруженные тела 4/4 |
| замкнутая форма конфликтности | `bankform` | 13 точек перебора; уровни 1/2/4 не пересекаются |
| регистры / разлив / КАДР СТЕКА / занятость | `cc_ab` | `Q(W)` 4/4; боевое тело — три числа **без единого такта карты** |
| где излом по регистрам | `knee` | вилка на 13 бюджетах из 13 |
| граница периода и связывающий канал | `tempo` | 0 нарушений на 643 замерах (воспроизведение требует собранного стенда) |
| расписание, MaxLive, влезает ли | `schedule` | тождественный отпечаток, а разница в 72 раза — ловит то, чего не видит модель |
| **что связывает и что переложить** | `relayout` | 8 якорей; **гейт годности 3/3** на телах, у которых связывающий уже замерен (`--gate`) |
| не уехало ли профилируемое тело | `twin` | пять условий, каждое проверено СРАБАТЫВАНИЕМ; два независимых генератора как ломка симметрии |
| ставки из замера вместо модельных | `calib` | самопроверка 18/18, все ворота проверены срабатыванием |
| кривая дополнения | `padsweep` | ворота написаны, **кривых замерено 0** — это ДОЛГ |
| влезет ли рабочее множество | `residency` | попадания в кеш 97.70 → 97.71 % |
| порядок вариантов, не видев их | `predict_fmt`, `predict_kernels` | порядок предсказан верно на 4 вариантах при 2 длинах из 3 |
| состояние окружения | `precheck`, `tempo_cli doctor` | заведены после ШЕСТИ отказов обвязки за сутки |

## Что из этого НЕ отработало на железе (долг, а не готовность)

* фазовый замер **времени** на боевом ядре — не снят;
* якорь харнесса на отгруженном внимании — отказался мерить при занятой карте;
* проверка диспетчеризации фаз — встала на застарелом файле блокировки;
* свип дополнений — не доведён ни разу.

Соответствие «код фазы → снятая фаза» взято **чтением исходника**. Если код диспетчеризуется
не туда, самопроверка выдаст доли **без единого признака ошибки**. Это записано в
`docs/NOT_YET.md` и не считается готовым.
