# `tempo/core/graph/` — теория графов конвейера

**Это СОБСТВЕННЫЙ код правообладателя, а не третья сторона.** Он покрыт TRL наравне с
остальным Произведением. Полная опись происхождения — с точностью до строк источника —
в `docs/journal/GRAPH_PROVENANCE.md`.

## Почему это здесь, а не в плагине

Ни одного архитектурного знания: потоки, паросочетания, топологический порядок, критический
контур, решётка разбиений. Всё это одинаково для любой машины, и именно поэтому лежит в
конвейере. Гейт G1 проверяет отсутствие имён архитектур во всём этом каталоге.

Кто здесь используется по делу: `max_mean_cycle` (точный алгоритм Карпа с восстановлением
самого критического контура) — это **`RecMII`** в `core/model/bound.py`, то есть максимум по
циклам графа зависимостей отношения суммы задержек к числу оборотов.

## Лицензионная история (важна, а не декоративна)

До 2026-08-02 эти файлы лежали в каталоге `vendor/`, а п. 4.1 лицензии называл `vendor/`
каталогом **третьих лиц**. Буквальное чтение выводило собственный код правообладателя
из-под собственной лицензии. Исправлено переносом сюда и правкой п. 4.1 (теперь он ссылается
на `third_party/`, который заведён **пустым**). См. `NOTICE`.

## Самопроверки

Каждый файл запускается сам и возвращает ноль при успехе:

```bash
python3 tempo/core/graph/flows.py        # 16/16, дифф-тесты против независимых реализаций
python3 tempo/core/graph/graphs.py       # 46/46, средний цикл сверен ПЕРЕБОРОМ ВСЕХ контуров
python3 tempo/core/graph/partitions.py   # 8/8
```

Они входят в `tests/test_tools_selftest.py` — фальсификатор миграции: перенос считается
состоявшимся только после того, как самопроверка перенесённого файла прошла на новом месте.
